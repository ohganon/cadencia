Tablero de estilo «Dominó Pop»: rediseño completo a partir de 222 diseños de interfaz de juegos móviles. Juega con la pantalla del centro.

Más pantallas

Las pantallas de decisión siguen las reglas del proyecto: opciones del mismo tamaño, precio a la vista y nada de cuentas atrás falsas.

El sistema

Fondo azul intenso, piezas de colores con contorno de tinta y botones que se hunden al pulsar. Cada color tiene un trabajo y no se usa para otra cosa.

Nunito, de 600 a 900: textos de servicio, ayudas y precios. Redondeada como los títulos, pero muy legible en tamaño pequeño. Licencia SIL OFL.

Botones

Pulsa cualquiera: el botón se hunde 4 px y su canto oscuro se estrecha. Un único gesto de respuesta para toda la interfaz.
