Tablero de «Dominó Pop», el tema que el juego trae por defecto. Juega con la pantalla del centro. Los demás temas están en la página de temas.

Más pantallas

Las pantallas de decisión siguen las reglas del proyecto: opciones del mismo tamaño, precio a la vista y nada de cuentas atrás falsas.

El sistema

Azul liso de fondo, marfil para lo que se toca y tinta para los contornos finos. El color fuerte se reserva: verde para avanzar, amarillo para lo que cae y lo que se gana, coral solo para las campanas.

Botones

Pulsa cualquiera: baja 3 px y su canto se estrecha. Solo hay dos tipos: verde para la acción principal de la pantalla y marfil para todo lo demás.
