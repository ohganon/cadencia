Scope: Cadencia themes page. It shows all 11 player-selectable themes on one shared screen engine, plus the in-game Ajustes › Apariencia theme picker. Experience mode for the page. The picker screen inside the phone is Operate mode.

## Direction contract

THESIS: one game, eleven looks. Dominó Pop (v2, quieter) is the default. The other ten change only tokens, the canvas palette and the copy tone: Mesa de juego, Calma premium, Gráfico y limpio, Cine negro, Tinta japonesa, Bauhaus, Brutalista, Risografía, Nocturno and Nórdico.

FORM: pinned by the client on 17/11/2026: «darle la opción al usuario de poder escoger entre varios diseños, poniendo domino pop como principal ... tienen que estar perfectamente diseñados». Dominó Pop: «muy abrumador y se nota muy IA».

RULES: a theme never changes rules, levels, prices or progress; every popup shows the real screen underneath; body text contrast stays at 4.5:1 or better in every theme.
